# Mouratech PDF

Leitor e assinador de PDFs para Windows de 64 bits. Edição pública de teste, versão 1.4.0.

## Baixar
[Baixar Mouratech PDF para Windows x64](https://github.com/mouratech-udi/mouratech-pdf/releases/latest/download/Mouratech-PDF-Windows-x64.msi). O [projeto com código-fonte e licenças](Mouratech-PDF-Fonte-1.4.0.zip) está disponível neste repositório. Para consultar as versões, abra **Releases**, escolha a versão mais recente e baixe **Mouratech-PDF-Windows-x64.msi**. Execute o instalador e abra **Mouratech PDF** pelo menu Iniciar.

## Recursos
Leia PDFs com miniaturas, zoom e busca por texto. Use Ferramentas para destacar trechos, inserir ou remover notas, unir, dividir e reorganizar páginas ou proteger uma cópia com senha. Insira texto ou uma assinatura por imagem. Para assinar digitalmente, selecione um certificado A1 compatível instalado no Windows. A assinatura individual ou em lote gera cópias assinadas e preserva os originais. O carimbo identifica o titular, o emissor e a hora com fuso. O processamento ocorre no computador do usuário.

[Consultar o guia de uso](LEIA-ME.md) · [Consultar a licença](LICENSE.md)

Para relatar um problema, descreva os passos e a versão do Windows. Use arquivos fictícios como exemplo e mantenha dados pessoais, certificados e chaves privadas fora de relatos públicos.
