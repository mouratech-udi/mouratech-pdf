# Mouratech PDF

Leitor e assinador de PDFs para Windows de 64 bits. Edição pública de teste, versão 1.7.0.

## Baixar
[Baixar Mouratech PDF para Windows x64](https://github.com/mouratech-udi/mouratech-pdf/releases/latest/download/Mouratech-PDF-Windows-x64.msi). O [projeto com código-fonte e licenças](Mouratech-PDF-Fonte-1.7.0.zip) está disponível neste repositório. Para consultar as versões, abra **Releases**, escolha a versão mais recente e baixe **Mouratech-PDF-Windows-x64.msi**. Execute o instalador e abra **Mouratech PDF** pelo menu Iniciar.

## Recursos
Leia PDFs com miniaturas, zoom e busca por texto. Use Ferramentas para destacar trechos, inserir ou remover notas, unir, dividir e reorganizar páginas ou proteger uma cópia com senha. Insira texto ou uma assinatura por imagem. Para assinar digitalmente, selecione um certificado A1 compatível instalado no Windows. A assinatura individual ou em lote gera cópias assinadas e preserva os originais. A assinatura abre na terceira página por padrão, ou na última disponível em PDFs menores. O campo Página para assinar permite escolher outra página, inclusive na revisão individual de cada arquivo do lote. O carimbo identifica o titular, o emissor e a hora com fuso. O processamento ocorre no computador do usuário.

[Consultar o guia de uso](LEIA-ME.md) · [Consultar a licença](LICENSE.md)

Para relatar um problema, descreva os passos e a versão do Windows. Use arquivos fictícios como exemplo e mantenha dados pessoais, certificados e chaves privadas fora de relatos públicos.




## Impressão integrada

Configure a impressora física preferida em Ferramentas. Assinar digitalmente salva a cópia assinada. Assinar e imprimir também envia a cópia à impressora escolhida.

Em Ferramentas → Configurar impressora virtual PDF, escolha a pasta de entrada. O aplicativo cria Mouratech PDF usando o componente Microsoft Print to PDF do Windows. Mantenha a janela principal aberta ou minimizada e salve as impressões nessa pasta. O Windows ainda solicita o destino do PDF. Os novos arquivos abrem automaticamente para conferência e assinatura.
